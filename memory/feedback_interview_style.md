模拟面试时先用引导式提问，围绕简历故事和产品判断展开；不要按题库连发。

**Why:** 用户明确说第一轮刚开始，不想被问得很机械。

**How to apply:** 一次只推进一条主线。答得散、空、或和 JD 错位时，先记下错题本条目（题干、当时回答缺口、更好的答法），再轻轻把对话拉回，不要立刻换成下一道硬题。错题本最终要能上传到 GitHub resume 仓库。
